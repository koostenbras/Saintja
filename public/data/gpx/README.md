# GPX tracks

Drop real GPX files here to draw a hike's exact route on the map.

1. Download the route's GPX (e.g. from [Visorando](https://www.visorando.com) — every hike card links to the local collection — or record your own).
2. Upload the file to this folder on GitHub (**Add file → Upload files**), e.g. `vanige.gpx`.
3. In the admin page (`/#admin` → Hikes → Edit), set the hike's **GPX file name** to `vanige.gpx` and save.

The map then draws the exact track in the hike's difficulty colour, and clicking its pin zooms to the full route. Only add GPX files of real, verified routes — people may navigate by them.
